===================================================
PRAGMATIC BALLOONING APP - COMPLETE USER MANUAL
===================================================

This manual contains everything you need to know to use, share, and install the Manufacturing Inspection Ballooning application from scratch.

---------------------------------------------------
1. REQUIREMENTS FOR A NEW SYSTEM
---------------------------------------------------
This project has been heavily optimized to be 100% self-contained. The AI scanner, PDF renderer, and database systems have all been embedded directly into the application. 

You DO NOT need Python, you DO NOT need MongoDB, and you DO NOT need to download 2.5GB of EasyOCR AI models anymore!

(Note regarding MongoDB: I have completely rewritten the backend server. It will now automatically detect if MongoDB is missing and switch to a high-speed 'In-Memory Mode'. This allows you to use the entire application flawlessly without ever installing a database! You simply export your finished balloons to Excel to save your work.) The visual quality and AI accuracy will be exactly the same as you see on your main laptop.

The ONLY thing you need to download on a brand new system is:
1. Node.js (LTS Version)
   Download link: https://nodejs.org/en/download/

---------------------------------------------------
2. HOW TO MIGRATE & RUN FROM SCRATCH
---------------------------------------------------
STEP 1: Copy the entire "pragmatic_project" folder to a USB drive or Cloud Storage.
STEP 2: Paste the folder onto the Desktop of the new laptop.
STEP 3: Ensure Node.js is installed on the new laptop.
STEP 4: Open the "pragmatic_project" folder and double-click the file named: Run_App.bat

That's it! 
- You DO NOT need to open VS Code. 
- You DO NOT need to type any terminal commands.
- The Run_App.bat script is highly intelligent: it detects if it's running on a new system from scratch and will automatically download the necessary dependencies silently in the background before launching the app in your browser perfectly.

---------------------------------------------------
3. HOW TO USE THE WEB INTERFACE
---------------------------------------------------
STEP 1: UPLOAD YOUR DRAWING
- Click the large "Click to upload or drag and drop" area.
- Select your engineering drawing (PDF format is recommended, but PNG/JPG are also supported). The PDF rendering quality is flawlessly integrated.

STEP 2: AUTO-DETECT DIMENSIONS
- Click the blue "Auto Detect" button in the left panel.
- The system's lightweight, high-speed AI will scan the entire drawing (ignoring title blocks and tables) and automatically place numbered red balloons on all detected engineering dimensions, tolerances, and text.
- If you want to start over, click "Clear All Ballooning".

STEP 3: MANUALLY ADD BALLOONS (Optional)
- Click the blue "Add Dimension" button.
- Click and drag your mouse over a dimension on the drawing to manually draw a box and create a new balloon.

STEP 4: EDIT BALLOON PROPERTIES
- Click on any red balloon on the drawing.
- Look at the right panel to edit its details:
  * Balloon Number: Change the identifying number.
  * Description / Symbol: Click any of the shortcut symbols (like Ø, ±, °, etc.) to instantly insert them! The system uses standard UTF-8 encoding so these symbols are perfectly preserved.
  * Value, +Tolerance, -Tolerance.
- All changes are automatically saved as soon as you click outside the text box!

STEP 5: EXPORT TO EXCEL
- Click the "View Characteristics Table" button to see a summary of all balloons.
- Click the green "Download Excel" button to export all your balloon data into an Excel spreadsheet (.xlsx).
- You can now use this spreadsheet for your inspection reports!

---------------------------------------------------
4. HOW TO SHUT DOWN THE APP
---------------------------------------------------
When you are completely finished using the app:
1. Close your web browser tab.
2. Close the black terminal windows that opened when you started the app. 
   (This safely turns off the background servers).
